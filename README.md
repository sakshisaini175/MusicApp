# 🎶 Vibes - Free Indian Music Player

Vibes is a simple web-based music player that streams **Hindi & Punjabi songs** from Archive.org and other free sources.  
It’s designed with an Indian audience in mind, featuring categories like **Sad Songs, Lofi Beats, Chill Songs, Bhajan, and Qawwali**.

---

## 🚀 Features
- Browse songs by category:
  - Sad Songs
  - Lofi Beats
  - Chill Songs (DJ, Party, Marriage hits)
  - Bhajan (Devotional)
  - Qawwali (Sufi devotional)
- Infinite scroll to load more tracks
- Favorites system (save songs locally)
- Search bar for custom queries
- Simple, responsive UI with TailwindCSS
- Live listener count simulation
- Audio player with play, pause, next, and previous controls

---

